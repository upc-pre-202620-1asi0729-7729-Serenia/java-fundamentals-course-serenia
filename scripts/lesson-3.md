# Guion · Lección 3: Decisiones y bucles (5 min)

**Objetivo:** controlar el flujo de un programa mediante condicionales `if-else` y automatizar tareas repetitivas con los bucles `for` y `while`.
**Editor:** JDoodle (`starter-files/lesson-3`). Ejemplo resuelto en `completed-examples/lesson-3`.
**Recurso visual:** un camino con bifurcación (flecha izquierda o derecha) para las decisiones y una pista de carreras circular (vueltas con contador) para los bucles. Usar siempre el mismo color por estructura durante todo el video.

**Colores por estructura (mantener en todo el video):** `if` / `else` = amarillo · `for` = cian · `while` = rosa · verdadero / se ejecuta = verde · falso / se salta = rojo. Los tipos de dato conservan los colores de la lección 2: `String` = azul · `int` = verde · `double` = naranja · `boolean` = morado.

* Enfatizar la sangría (indentación) dentro de las llaves para que los estudiantes se acostumbren a escribir código limpio.
* Resaltar con el mismo color cada estructura (`if` / `else`, `for`, `while`) en las animaciones, en el código y en las tarjetas de resumen.
* Mostrar el resultado de la consola resaltado unos segundos después de cada ejecución.
* Dejar la pantalla de pausa visible al menos 5 segundos antes de continuar con el resumen.
