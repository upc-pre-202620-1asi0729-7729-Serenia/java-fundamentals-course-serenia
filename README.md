# Fundamentos de Java para Principiantes

## Resumen del Curso
Este curso de 60 minutos introduce a estudiantes de secundaria (12 a 17 años) a los fundamentos esenciales de la programación con Java y a la programación orientada a objetos (POO). El contenido está diseñado para aprender desde cero mediante explicaciones visuales, ejemplos cotidianos y retos interactivos. ¡No requiere descargar nada! Todo se ejecuta directamente desde el navegador mediante editores en línea gratuitos.

* **Duración total**: ~60 minutos
* **Público Objetivo**: Estudiantes de secundaria de 12 a 17 años sin experiencia previa en programación
* **Prerrequisitos**: Ninguno (solo saber usar un navegador)
* **Herramientas necesarias**: Navegador web moderno (Google Chrome, Mozilla Firefox, Safari o Microsoft Edge)
* **Repositorio de Código Fuente**: [https://github.com/upc-pre-202620-1asi0729-7729-Serenia/java-fundamentals-course-serenia](https://github.com/upc-pre-202620-1asi0729-7729-Serenia/java-fundamentals-course-serenia)

## Secuencia de Lecciones

### Lección 1: ¿Qué es la programación y cómo funciona Java? (8 minutos)
* **Descripción**: Descubre qué es un programa informático, cómo las computadoras interpretan instrucciones y por qué Java es uno de los lenguajes más populares del mundo para crear videojuegos, servidores y aplicaciones móviles. Escribiremos y ejecutaremos nuestro primer mensaje en consola.
* **Enlace**: [Ver la lección](https://www.youtube.com/link_video1)
* **Conclusiones clave**: Un programa es un conjunto ordenado de instrucciones; la función `main` es el punto de inicio de ejecución en Java; `System.out.println()` imprime texto en pantalla.
* **Empieza a programar**: [Abrir plantilla en Replit](https://replit.com/@tu-usuario/java-leccion-1-starter)

### Lección 2: Variables y tipos de datos: Guardando información (9 minutos)
* **Descripción**: Aprende cómo la computadora recuerda datos. Crearemos el perfil digital de un personaje de videojuego utilizando variables de texto (`String`), números enteros (`int`), números decimales (`double`) y valores lógicos (`boolean`).
* **Enlace**: [Ver la lección](https://youtu.be/qorS3gYNQBU)
* **Conclusiones clave**: Una variable es una caja con nombre y tipo de dato; Java requiere declarar el tipo antes del nombre; el operador `=` asigna un valor.
* **Práctica**: [Clic para programar en Replit](https://replit.com/@tu-usuario/java-leccion-2-starter)

### Lección 3: Estructuras de control: Decisiones y repeticiones (11 minutos)
* **Descripción**: Dale inteligencia a tus programas. Implementaremos decisiones con `if-else` y operadores lógicos para elegir caminos en una historia interactiva, y utilizaremos bucles `for` y `while` para repetir acciones automáticamente sin reescribir código.
* **Enlace**: [Ver la lección](https://www.youtube.com/link_video3)
* **Conclusiones clave**: `if (condición)` evalúa expresiones booleanas; `for` se emplea cuando conocemos el número de repeticiones; `while` repite mientras una condición sea verdadera.
* **Práctica**: [Clic para programar en JDoodle](https://www.jdoodle.com/ia/example-lesson3)

### Lección 4: Entrada por consola y métodos modulares (10 minutos)
* **Descripción**: Haz que tu programa interactúe con el usuario leyendo texto y números desde el teclado mediante la clase `Scanner`. Además, organizaremos el código en métodos (funciones) reutilizables con parámetros y valores de retorno.
* **Enlace**: [Ver la lección](https://www.youtube.com/link_video4)
* **Conclusiones clave**: La clase `Scanner` captura entradas del teclado; los métodos evitan duplicar lógica; `return` devuelve un resultado al bloque que invocó la función.
* **Práctica**: [Clic para programar en OnlineGDB](https://onlinegdb.com/example-lesson4)

### Lección 5: Introducción a la Programación Orientada a Objetos (14 minutos)
* **Descripción**: Modela elementos del mundo real dentro de tu código. Aprende la diferencia entre una clase (molde) y un objeto (instancia). Construiremos una clase `Mascota` con atributos privados, métodos constructores, comportamientos interactivos y métodos de acceso (`getters` y `setters`) aplicando encapsulación.
* **Enlace**: [Ver la lección](https://www.youtube.com/link_video5)
* **Conclusiones clave**: Una clase define atributos y comportamientos; el constructor inicializa el estado del objeto; la encapsulación protege los datos mediante atributos `private` y métodos `public`.
* **Proyecto final**: [Crea tu simulador de mascotas en JDoodle](https://www.jdoodle.com/ia/zx55-qn5q-434k)

### Lección 6: Buenas prácticas, depuración y siguientes pasos (8 minutos)
* **Descripción**: Revisa los errores más frecuentes que cometen los desarrolladores principiantes (olvido de punto y coma, discrepancia entre tipos de datos, errores de índice en arreglos). Aprende a interpretar los mensajes de error en la consola y descubre rutas recomendadas para continuar tu formación en desarrollo de software.
* **Enlace**: [Ver la lección](https://www.youtube.com/link_video6)
* **Conclusiones clave**: Leer el mensaje de la traza de error indica la línea exacta del fallo; mantener nombres descriptivos mejora la legibilidad; no temer a equivocarse al compilar.
* **Formulario de retroalimentación**: [Compartir proyecto final](https://forms.gle/)
